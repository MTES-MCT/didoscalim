# Retourne une date au format ISO 8601 avec la TZ

Retourne une date au format ISO 8601 avec la TZ

## Utilisation

``` r
date_heure_iso8601(date_heure)
```

## Arguments

- date_heure:

  date/heure

## Valeur de retour

une date/heure au format ISO 8601 avec la TZ

## Exemples

``` r
date_heure_iso8601("2022-02-02 07:00:02")
#> [1] "2022-02-02T07:00:02+0100"
```
