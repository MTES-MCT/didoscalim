# L'objet dido_attachment

L'objet dido_attachment inclus les champs :

- `rid` l'identifiant du jeu de données parent

- `title`

- `type`

- `description`

- `created_at`

- `last_modified`

- `published`

- `url` : l'url du fichier annexe
